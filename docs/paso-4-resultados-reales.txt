DIFERENCIAS ENTRE MOCK Y MODO REAL
────────────────────────────────────────────────────────────────────────────────

  El mock fue diseñado con el prompt inicial (v1). Los tests reales se
  ejecutaron con el prompt mejorado (v2 — prompt más conservador de Bryan).

  Caso: taller mecánico
    Mock v1:  features [authentication, roles_permissions, database, crud]
              estimado $37,200 – $99,400 MXN
    Real v2:  features [authentication, crud, database]
              estimado $33,900 – $91,800 MXN
    → OpenAI dejó roles_permissions en missingInformation porque el
      usuario no especificó roles distintos (solo "entrar con usuario
      y contraseña"). Más preciso.

  Caso: despacho de abogados
    Mock v1:  features [email_service], estimado $5,100 – $10,100 MXN
    Real v2:  features [], estimado $3,400 – $6,800 MXN
    → El usuario dijo "contactarme" sin mencionar formulario ni email.
      Con el prompt conservador, OpenAI no asume el feature.

  Caso: tienda + chatbot
    Mock v1:  complexity "complex", features 6, estimado $77,200 – $185,700 MXN
    Real v2:  complexity "medium", features 3, estimado $49,200 – $118,000 MXN
    → Con el prompt mejorado, OpenAI no sobre-estima la complejidad ni
      añade features sin mención explícita del usuario.

  CONCLUSIÓN:
    El prompt mejorado hace que la IA sea más honesta: solo interpreta
    lo que el usuario dijo, y deja el resto en missingInformation para
    que Bryan complete la cotización definitiva manualmente.
